# 多宫格拼图工具

多宫格拼图工具 v1.3.1 的 Netlify 静态部署版。

- 所有图片和视频在浏览器本地处理。
- 人像抠图模型随站点静态文件提供。
- 不依赖后端服务或云端 API。

直接打开 `index.html` 或使用 Netlify 部署即可。

## 首屏与动态背景修复（2026-10-09）

电影背景仍使用原来的红披风视频，小黑龙仍循环四种动作。页面先显示电影首帧，再开始视频下载；任意一张龙图片就绪后即可启动动画。示例拼图、龙图片和电影首帧改用 WebP，视频降为 960×540，原素材保留。

首屏样式直接包含在 HTML 内，功能脚本延后执行；只保留使用到的图标样式，人像抠图模型仍在需要时加载。示例图约 73 KB、龙图片合计约 56 KB、首帧约 29 KB、视频约 823 KB。网络响应速度仍取决于访问者到 Netlify 的连接。

修改 `assets/app-v14.css` 或功能脚本后，运行 `node scripts/build-fast-shell.cjs` 重新生成内联样式和脚本缓存版本。图片压缩脚本为 `scripts/optimize-assets.cjs`（需要 sharp）。

## 拼图比例与排版（v1.6）

预览上方可选择自动、两列、三列、横排、竖排、左主图和上主图排版；支持自动比例、1:1、4:3、3:2、16:9、9:16、3:4、2:3 和自定义比例。图片或设置变更后自动更新预览，导出尺寸与所选比例保持一致。

默认使用等比裁切铺满每个格子，低分辨率图片也会放大，不再因禁止放大导致第四张图片缩在格子中间。裁切可能去掉边缘；需要保留完整图片时选择“完整显示”，比例不匹配时会有留边。另提供“拉伸铺满”，但会改变图片形状。奇数张图片的末行铺满画布，不留下空格。

输出长边默认 2048 px，可选择 1024、4096 或按原图清晰度。预览使用轻量画布，只有生成导出时创建全分辨率画布。运行 `node scripts/test-collage-layout.cjs` 检查不同数量、排版、比例、间距和小图放大的回归测试。
